# CODEX TASK — Error Code Audit & Documentation

## Objective

Search the entire `supabase/functions/api/` directory for every error code string used in `errorResponse` and `procurementErrorResponse` calls. Compile them into a single markdown reference file.

---

## What to do

### Step 1 — Collect all error codes

Search all `.ts` files under `supabase/functions/api/` for the pattern:

```
errorResponse(
procurementErrorResponse(
```

For each call, extract:
- The **error code string** (first string argument, e.g. `"GE_PRUNE_BLOCKED_BY_GRN"`)
- The **HTTP status** (numeric argument, e.g. `400`, `403`, `500`)
- The **human-readable message** (last string argument)
- The **source file** (relative path)

Also search for `throw new Error(` patterns in the same files — extract those error strings too (they bubble up as 500s).

### Step 2 — Group and deduplicate

Group by **prefix** (the part before the first `_`):

| Prefix | Domain |
|--------|--------|
| `GE_` | Gate Entry |
| `GRN_` | Goods Receipt |
| `CSN_` | Consignment Note |
| `PO_` | Purchase Order |
| `STO_` | Stock Transfer Order |
| `RTV_` | Return to Vendor |
| `IV_` | Invoice Verification |
| `QA_` | Inward QA |
| `OS_` | Opening Stock |
| `PID_` | Physical Inventory |
| `SO_` | Sales Order |
| `MAT_` | Material Master |
| `VND_` | Vendor Master |
| `UOM_` | Unit of Measure |
| `AUTH_` | Authentication |
| `ACL_` | Access Control |
| `HR_` | HR module |
| `STOCK_` | Stock / Ledger |
| Others | Misc |

### Step 3 — Write the output file

Create file: `docs/PACE_ERP_ERROR_CODE_REFERENCE.md`

Format:

```markdown
# PACE ERP — Error Code Reference

Last updated: 2026-07-08
Auto-generated by Codex from source scan.

---

## How to read this table

| Column | Meaning |
|--------|---------|
| Code | The error_code string returned in API response |
| HTTP | HTTP status code |
| Message | Default message sent to frontend |
| Source | Handler file where this error is thrown |

---

## GE — Gate Entry

| Code | HTTP | Message | Source |
|------|------|---------|--------|
| GE_ID_REQUIRED | 400 | Gate entry id is required. | gate_entry.handlers.ts |
| ... | | | |

---

## GRN — Goods Receipt

...

(one section per domain prefix)
```

Include **every unique error code** found. If same code appears in multiple files, list all source files separated by `, `.

If a `throw new Error("CODE")` is caught and re-thrown as a response elsewhere, note it as `500 (thrown)` in the HTTP column.

---

## What NOT to do

- Do not modify any source files
- Do not add or remove error codes — just document what exists
- Do not skip `throw new Error(...)` patterns — they are real errors users see

---

## Output

Single file: `docs/PACE_ERP_ERROR_CODE_REFERENCE.md`

Commit message: `docs: add error code reference (Codex audit)`
